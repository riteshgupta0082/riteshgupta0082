## 👨‍💻 About Me

I'm a **DevOps Engineer with 3 years of experience** in cloud infrastructure, Infrastructure as Code (IaC), CI/CD automation, and deployment engineering.

I focus on building repeatable infrastructure workflows, automating delivery pipelines, integrating security checks, and improving infrastructure reliability using modern DevOps tools.

- ☁️ **Cloud:** Microsoft Azure
- 🏗️ **IaC:** Terraform
- 🔄 **CI/CD:** Azure DevOps, GitHub Actions, Jenkins
- 🔐 **DevSecOps:** Gitleaks, Terrascan, TFLint
- 💰 **Cost Visibility:** Infracost
- 🐳 **Containers:** Docker, Kubernetes
- ⚙️ **Automation:** PowerShell, Python, YAML
- 🤝 **Collaboration:** Git, GitHub, Jira
